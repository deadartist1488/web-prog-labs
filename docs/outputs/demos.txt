# Демонстрации: SQL-инъекция, хеширование, пул соединений

## SQL-инъекция
1) поиск, ввод "' OR '1'='1"
   уязвимый:  [(1, 'admin@library.local', 'admin'), (2, 'anna@example.com', 'user')]   <- утекли все пользователи
   безопасный: []
2) обход авторизации, email="admin@library.local' --", пароль любой
   уязвимый:  (1, 'admin')   <- вошли как admin без пароля
   безопасный: None
3) удаление данных, ввод "x'; DROP TABLE users; --"
   уязвимый: таблицы после атаки = []   <- таблица users удалена
   безопасный: таблицы = [('users',), ('sqlite_autoindex_users_1',)]

## Хеширование паролей
sha256 без соли: одинаковые хеши для одинаковых паролей: True (fcf730b6d95236ec...)
sha256: ~941,098 хешей/с на одном ядре -> перебор словаря быстрый
bcrypt rounds=10: 63 мс на хеш (~15.8 хешей/с), пример $2b$10$R9aF/H.08ohZDmNVkvpYEu...
bcrypt rounds=12: 269 мс на хеш (~3.7 хешей/с), пример $2b$12$qepd5nPLAJr38DJEsPw2ce...
bcrypt rounds=14: 1223 мс на хеш (~0.8 хешей/с), пример $2b$14$pEuycGuqbZ7IZPFwXkvoOu...
bcrypt: два хеша одного пароля различаются (соль): True; оба проверяются: True
